# Startup Tycoon

**Start Small. Build Smart. Own the Market.**

A native Godot 4 mobile business-city simulation. The first playable slice includes a procedural isometric startup city, touch/mouse camera interaction, selectable and upgradeable buildings, company creation, hiring, product development, daily economy progression, and local save/load.

## Run locally

1. Install Godot 4.7 or newer.
2. Import this folder and run `scenes/Main.tscn`.
3. For Android, configure the Godot Android export template and export the `Android` preset.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the architecture decision.
