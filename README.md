# Startup Tycoon

**Start Small. Build Smart. Own the Market.**

A native Godot 4 mobile business-city simulation. The v0.2.0 slice includes a generated Node3D business city with roads, water, bridges, terrain, districts, 3D building meshes, touch/mouse camera interaction, selectable and upgradeable buildings, company creation, hiring, product development, daily economy progression, offline progression, local analytics, and a Google Play Billing-ready offer catalog.

## Run locally

1. Install Godot 4.7 or newer.
2. Import this folder and run `scenes/Main.tscn`.
3. For Android, configure the Godot Android export template and export the `Android` preset.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the architecture decision. Real purchases are intentionally not claimed until a store billing adapter is connected and tested.
